# Промпт: пересдачи только по незакрытым дисциплинам

```
Дмитрий видит в «Пересдачах» слоты по дисциплинам, которые уже сдал: по Эконометрике
у него 4, по Философии 5, но слоты всё равно показываются. Разберись с логикой вкладки.

Правило: пересдать можно только то, что не закрыто. Сданная дисциплина закрыта, даже
если пересдачи в истории были. Пересдачи — это способ закрыть долг, а не переиграть
хорошую оценку.

Требования:
- Список фильтруется на сервере по зачётке студента, не в интерфейсе.
- Слот показывается, только если дисциплина есть в учебном плане, а статус — «долг»
  или «не сдано». Лимит пересдач — 2, при исчерпании запись тоже закрыта.
- Своя существующая запись видна всегда: её нужно уметь отменить, даже если статус
  дисциплины поменялся.
- POST на запись проверяет то же самое: обойти форму прямым запросом нельзя.
- В шапке вкладки объясни правило одной фразой, чтобы «почему тут нет моего долга»
  не возникало.

Проверь: у Анны в списке ровно её долги (Эконометрика, Философия), у Дмитрия —
только Международная торговля. Прямой POST на сданную дисциплину → 400.
Добавь это в scripts/verify-idor.ts.
```
