# Промпт: сквозной путь заявки

```
Сделай сквозной путь заявки.
Студент: шаблоны (справка об обучении, справка для стипендии, заявление на пересдачу),
срок по типу, статусы «подана → в работе → готова/отклонена», история изменений.
Чужой id — 404, не 403.
Сотрудник: очередь с фильтром по статусу и просрочке, смена статуса, обязательный
комментарий при отказе.
Требования:
- мутация на сервере, затем ревалидация; без оптимистичных обновлений, которые теряются;
- причина отказа хранится и видна студенту;
- покажи, что произойдёт при повторном нажатии «Отправить».
```
