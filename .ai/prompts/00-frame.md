# Промпт: рамка проекта

Отправляется один раз в начале работы, до любого кода.

```
Ты работаешь над прототипом личного кабинета студента для конкурса MGIMO AI Challenge.
До первой правки прочитай AGENTS.md и PLAN.md.
Ответь тремя пунктами:
1) перечисли дословно инварианты, которые обязан соблюдать;
2) назови файлы, которые собираешься изменить;
3) назови проверку, которая докажет, что результат достигнут.
Код не пиши, пока я не подтвержу план.
```

Ожидаемый результат: список инвариантов, план правки, проверка. Если ответ общий («понял, что важно качество») — промпт повторяется с требованием дословности.
