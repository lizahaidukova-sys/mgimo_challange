# Промпт: мобильная проверка 360 px

```
Пройди все экраны на ширине 360 px как проверяющий.
Найди:
- горизонтальную прокрутку;
- цели меньше 44×44 px и зазоры меньше 8 px;
- обрезанный или перенесённый по слогам текст;
- статусы, различимые только по цвету;
- потерянный видимый фокус;
- поля с размером шрифта меньше 16 px.
Дай список дефектов с файлом и строкой. Общие рекомендации не принимаются.
```
