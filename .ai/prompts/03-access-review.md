# Промпт: проверка доступа как атакующий

```
Проверь модель доступа как атакующий.
У тебя есть сессия студента А. Перечисли 10 способов получить данные студента Б:
прямой id, query-параметр, подмена cookie, staff-маршрут, server action без проверки,
перебор, кэш, редирект, вложенный ресурс, массовое присвоение полей.
Для каждого напиши строку кода, которая это блокирует.
Если способ не заблокирован — отметь как дефект, не придумывай обход.
```
