# Промпт: админка для жюри

```
Жюри должно править данные прототипа без SSH и SQL: пары, преподаватели,
аудитории, дисциплины, семестры, люди. Сделай третью роль admin и раздел /admin.

Требования:
- Вход admin@demo.local / demo12345. Роль admin не равна staff: сотрудник
  деканата админку не открывает, студент — тем более. Проверь это на сервере,
  а не скрытой кнопкой.
- По каждой сущности: список, поиск по основному полю, создание, правка,
  удаление. Правка — частичная: PATCH с одним полем не должен сбрасывать
  остальные (проверь формой, где меняется только комментарий).
- Удаление со связями блокируется с понятным текстом, а не каскадит:
  жюри не должно снести половину демо одним кликом. Себя администратор
  удалить не может.
- Изменения идут в живую базу: правка пары видна студенту в расписании.
- Кнопка «перезапустить демо» возвращает исходные данные и не разлогинивает.
- Мобильный первым: на 360 px таблица превращается в карточки,
  горизонтальной прокрутки нет.

Что проверить и показать:
- tsc без ошибок, verify:idor зелёный, включая три проверки на /api/admin.
- Сид печатает 4 аккаунта.
- Curl-сценарий: создание преподавателя, правка, удаление связанного
  (400), удаление себя (400), создание пары и её появление у студента.
```
