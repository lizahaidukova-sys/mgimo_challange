# Цифровой деканат — концепт личного кабинета студента

Прототип для MGIMO AI Challenge, номинация «Вайб-кодинг». **Это концепт для конкурса, а не официальный сервис МГИМО.** Логотип вуза не используется; данные вымышленные.

## Статус

| Фаза | Статус |
|---|---|
| Ф0. План, каркас, документация процесса | готово |
| Ф1–Ф4. Приложение: вход, изоляция, расписание, оценки, заявки, уведомления, кабинет деканата | готово |
| Ф5. Деплой на VPS | ждёт сервер от заказчика |
| Ф6. PDF-описание и видео | в работе, дедлайн 22.11 23:59 МСК |

## Что это

Один экран вместо пяти: расписание, оценки, заявки и объявления — в одном кабинете, который нормально работает с телефона за пару касаний.

Сверх обязательного ядра:

- **светофор сессии** — правила по долгам и оценкам, а не «магия ИИ»;
- **заявка как трекер** — срок, статус, причина отказа, история;
- **«что изменилось»** — переносы, новые оценки и смены статусов с прошлого визита.

## Запуск

```bash
cp .env.example .env          # вписать SESSION_SECRET (openssl rand -hex 32)
npm ci
npm run seed                  # демо-данные и три аккаунта
npm run dev                   # API :8787 + фронт :5173
```

Production-сборка:

```bash
npm run build                 # dist/
npm start                     # API и статика на :8787
```

Тестовые аккаунты (пароль у всех — `demo12345`):

| Логин | Роль | Что видно |
|---|---|---|
| `student1@demo.local` | студент | два долга, жёлтый светофор, две заявки |
| `student2@demo.local` | студент | всё закрыто, но один просроченный долг, другая заявка |
| `staff@demo.local` | деканат | очередь заявок, объявления, правка пар |

Все ФИО, оценки, аудитории и заявки вымышлены.

Секреты и база в репозиторий не попадают. Одна команда проверяет всё: `npm run verify` (типы, правила светофора, секреты, 15 проверок доступа).

## Лицензии

Шрифты — Inter (SIL OFL 1.1). Иконки — Lucide (ISC). Сторонние ассеты с иными условиями не используются.
