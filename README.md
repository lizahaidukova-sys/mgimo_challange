# Цифровой деканат — концепт личного кабинета студента

Прототип для MGIMO AI Challenge, номинация «Вайб-кодинг». **Это концепт для конкурса, а не официальный сервис МГИМО.** Логотип вуза не используется; данные вымышленные.

|---|---|

## Что это

Один экран вместо пяти: расписание, оценки, заявки и объявления — в одном кабинете, который нормально работает с телефона за пару касаний.

Сверх обязательного ядра:

- **светофор сессии** — правила по долгам и оценкам, а не «магия ИИ»;
- **заявка как трекер** — срок, статус, причина отказа, история;
- **«что изменилось»** — переносы, новые оценки и смены статусов с прошлого визита.

Дополнительно: зачётная книжка по семестрам, пересдачи с подтверждением записи, документы и стипендия, переписка с деканатом, вложения к заявкам (справка от врача) и раздел **админки** для жюри — таблицы базы без SSH и SQL.

## Запуск

```bash
cp .env.example .env          # вписать SESSION_SECRET (openssl rand -hex 32)
npm install                   # npm ci тоже работает, но lock собран на Windows: на Linux надёжнее install, см. docs/10-deploy.md
npm run seed                  # демо-данные и четыре аккаунта
npm run dev                   # API :8787 + фронт :5173
```

Production-сборка:

```bash
npm run build                 # dist/
npm start                     # API и статика на :8787
```

Тестовые аккаунты (пароль у всех — `demo12345`):

| Логин | Роль | Что видно |
|---|---|---|
| `student1@demo.local` | студент | два долга, жёлтый светофор, две заявки |
| `student2@demo.local` | студент | один просроченный долг по торговле, красный светофор, другая заявка |
| `staff@demo.local` | деканат | очередь заявок, объявления, правка пар |
| `admin@demo.local` | админ | таблицы пар, преподавателей, аудиторий, дисциплин, семестров и людей; перезапуск демо |

Все ФИО, оценки, аудитории и заявки вымышлены.

Секреты и база в репозиторий не попадают. Одна команда проверяет всё: `npm run verify` (типы, правила светофора, секреты, 39 проверок доступа).

## Регламент конкурса

Работу подаёт капитан команды через личный кабинет до 22.11 23:59 МСК. Исходный код
принимается ссылкой на GitHub/GitVerse **или архивом на Яндекс/Google Диске**.
Факт отправки передаёт организатору исключительные права на материалы (п. 6.2–6.4 Регламента).

## Лицензии

Шрифты — Inter (SIL OFL 1.1). Иконки — Lucide (ISC). Сторонние ассеты с иными условиями не используются.
