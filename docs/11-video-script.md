# Сценарий видео (≤ 5 минут)

Формат: запись экрана телефона или окна 360 px + голос. Один сквозной путь, без монтажных трюков.

| Время | Кадр | Что говорим |
|---|---|---|
| 0:00–0:20 | Страница входа | «Это концепт кабинета студента для конкурса, не официальный сервис. Три тестовых аккаунта — два студента и деканат». |
| 0:20–0:50 | Вход первым студентом → главная | «Один экран отвечает на три вопроса: что сегодня, что изменилось, что с сессией. Светофор жёлтый: два долга, ближайший — 24 ноября». |
| 0:50–1:20 | Расписание, переключение день/неделя | «Перенос виден как статус, а не как примечание: было 12:10, стало 14:00. Отмена — отдельным цветом и словом». |
| 1:20–1:50 | Успеваемость | «Светофор считают правила, не модель: статус и приоритет воспроизводимы. ИИ только переформулирует объяснение». |
| 1:50–2:30 | Создание заявки | «Справка за четыре шага: тип, назначение, формат, отправка. Срок — в рабочих днях, сразу видно дату». |
| 2:30–3:00 | Вход сотрудником → очередь | «Деканат видит очередь по сроку, а не по дате подачи. Меняет статус, причина отказа обязательна». |
| 3:00–3:30 | Возврат студентом → заявка и уведомление | «Студент видит новый статус и комментарий без перезагрузки и без звонка». |
| 3:30–4:00 | Продолжение после перерыва | «Закрываем вкладку, входим заново — работа продолжается с того же места: заявка, статус, история». |
| 4:00–4:30 | Телефон 360 px | «Тот же путь на телефоне: нижняя навигация, цели под палец, без горизонтальной прокрутки». |
| 4:30–5:00 | Проверка изоляции | «Второй студент не видит заявку первого: по прямой ссылке — «не найдено». Это проверяется скриптом, а не глазами». |

## Технические требования

- Разрешение: 1080×1920 (телефон) или 1280×720 (окно).
- Звук: микрофон, без музыки.
- Субтитры: не обязательны, но текст в кадре читается.
- Не показывать: `.env`, реальные почты, ключи, консоль с секретами.
- Хостинг видео: YouTube (unlisted), VK Видео, RuTube или Диск.

## Что подготовить до записи

1. `npm run seed` — свежие данные.
2. Заранее создать одну заявку первым студентом, чтобы было что показать в очереди.
3. Очистить уведомления нельзя намеренно: непрочитанные нужны для кадра.
4. Отключить уведомления ОС, чтобы не попадали в кадр.
