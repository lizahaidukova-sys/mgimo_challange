## 5. Порядок отправки

1. Войти в кабинет конкурса.
2. «Вайб-кодинг» → «Моя работа».
3. Проверить, что у всех участников стоят ✓ напротив согласия, билета и Регламента.
4. Заполнить ссылки и комментарий с тестовыми аккаунтами.
5. Отправить. До 22.11 23:59 МСК работу можно заменить — учитывается последняя версия.

## 6. Если что-то сломалось перед отправкой

| Симптом | Что проверить |
|---|---|
| Белый экран | `journalctl -u dean -n 50`; собран ли `dist/` |
| «Сервер недоступен» | жив ли процесс, отвечает ли `/api/health` |
| Вход не держится | схема в `APP_ORIGIN` совпадает с адресом в браузере (`https`/`http`) |
| Пустое расписание | выполнен ли `npm run seed` после установки |
| Данные чужие | выполнить `npm run seed` — база пересоздаётся |
