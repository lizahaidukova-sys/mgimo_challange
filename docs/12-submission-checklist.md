# Чек-лист отправки работы

Всё, что нужно сделать руками, в порядке выполнения. Отправку делает капитан команды.

## 1. Документы участника (блокирует отправку)

| Шаг | Где | Готово |
|---|---|---|
| Скачать бланк согласия на обработку ПД (.docx) | кабинет → Профиль | ☐ |
| Распечатать, заполнить, подписать | — | ☐ |
| Скан или фото согласия | Профиль → «Согласие на обработку персональных данных» | ☐ |
| Скан разворота студенческого билета (ФИО, вуз, срок действия) | Профиль → «Студенческий билет» | ☐ |
| Галочка согласия с Регламентом | Профиль, конец раздела | ☐ |

Файлы: `.pdf`, `.jpg`, `.jpeg`, `.png`, до 5 МБ. Заменить можно только в течение 60 минут после загрузки.

Пока у капитана (и у каждого участника команды) нет всех трёх отметок, форма отправки в разделе «Моя работа» не появляется.

## 3. Репозиторий

| Шаг | Команда | Готово |
|---|---|---|
| Создать репозиторий на GitHub или GitVerse | — | ☐ |
| Запушить | `git remote add origin <url> && git push -u origin main` | ☐ |

## 5. Порядок отправки

1. Войти в кабинет конкурса.
2. «Вайб-кодинг» → «Моя работа».
3. Проверить, что у всех участников стоят ✓ напротив согласия, билета и Регламента.
4. Заполнить ссылки и комментарий с тестовыми аккаунтами.
5. Отправить. До 22.11 23:59 МСК работу можно заменить — учитывается последняя версия.

## 6. Если что-то сломалось перед отправкой

| Симптом | Что проверить |
|---|---|
| Белый экран | `journalctl -u dean -n 50`; собран ли `dist/` |
| «Сервер недоступен» | жив ли процесс, отвечает ли `/api/health` |
| Вход не держится | схема в `APP_ORIGIN` совпадает с адресом в браузере (`https`/`http`) |
| Пустое расписание | выполнен ли `npm run seed` после установки |
| Данные чужие | выполнить `npm run seed` — база пересоздаётся |
