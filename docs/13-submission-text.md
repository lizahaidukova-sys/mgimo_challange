## Исходный код

**Репозиторий:** https://github.com/lizahaidukova-sys/mgimo_challange/tree/dev

Ветка `dev`, 29 коммитов, публичный доступ без регистрации. История показывает ход работы по итерациям, а не один финальный слепок.

Что внутри: код (`server/`, `src/`, `shared/`), документация (`docs/`, `.ai/prompts/`), проверки (`scripts/`), установщик (`deploy/`), собранное описание работы и два видео.

Запуск:

```bash
cp .env.example .env      # вписать SESSION_SECRET
npm install               # npm ci на Linux не сходится с lock-файлом, см. docs/10-deploy.md
npm run seed
npm run build
npm start                 # http://localhost:8787
```

**Резервная копия:** зип-архив `dean-office-source.zip` (9,3 МБ, 144 файла) на Яндекс Диске — то же содержимое ветки `dev`, если GitHub недоступен.

## Видео

Два файла, один сценарий в двух видах, без голоса, подписи вшиты:

| Файл | Кадр | Длительность |
|---|---|---|
| `demo-mobile.mp4` | 780×1688 (телефон 390×844 @2x) | ~2:15, 28 кадров |
| `demo-desktop.mp4` | 1440×900 | ~2:15, те же 28 кадров |

Сквозной проход: вход, главная, расписание (день и неделя), успеваемость с вкладкой долгов, зачётка, заявки, отклонённая заявка со справкой, пересдачи и подтверждение записи, уведомления, переписка, новая заявка, документы, профиль, кабинет деканата целиком и админка для жюри. Запись воспроизводится одной командой: `npm run record:demo` и `npm run record:demo:desktop`.

## Что реализовано сверх обязательного ядра

- **Светофор сессии** — правила по долгам и оценкам, а не генерация модели: воспроизводимо и проверяемо.
- **Заявка как трекер** — срок в рабочих днях, статусы, обязательная причина отказа, история.
- **«Что изменилось»** — переносы, оценки и статусы за последние три дня.
- **Кабинет деканата** — очередь по сроку, смена статуса, объявления, правка пар.

## Безопасность

Студент видит только свои данные. Чужой идентификатор возвращает 404 — так же, как несуществующий. Пароли хранятся как scrypt-хеш, сессия — в `httpOnly` cookie с `Secure` и `SameSite=Lax`. Секреты только в `.env`, в клиентский бандл не попадают. Данные вымышленные, подключения к системам вуза нет.

## Ограничения

Интервью с реальными студентами не проводились: гипотезы помечены как гипотезы, в документе указан способ их проверки. Скринридер не тестировался. LLM-функция опциональна — без ключа объяснения формируются шаблоном.
