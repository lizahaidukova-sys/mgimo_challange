## Исходный код

Зип-архив `dean-office-source.zip` (5,5 МБ) — приложить ссылкой на Яндекс Диск вместе с остальными файлами.

Внутри: код, документация (`docs/`), проверки (`npm run verify`), установщик (`deploy/`). Запуск:

```bash
cp .env.example .env      # вписать SESSION_SECRET
npm install               # npm ci на Linux не сходится с lock-файлом, см. docs/10-deploy.md
npm run seed
npm run build
npm start                 # http://localhost:8787
```

## Описание работы

`Описание работы — Цифровой деканат.pdf` — 10 страниц со скриншотами: проблема, обоснование разделов, перечень ИИ-инструментов, ключевые промпты, безопасность простыми словами, время и расходы, ограничения.

## Видео

`Демо — Цифровой деканат.mp4` — 56 секунд, 12 экранов, без голоса, подписи вшиты.

## Что реализовано сверх обязательного ядра

- **Светофор сессии** — правила по долгам и оценкам, а не генерация модели: воспроизводимо и проверяемо.
- **Заявка как трекер** — срок в рабочих днях, статусы, обязательная причина отказа, история.
- **«Что изменилось»** — переносы, оценки и статусы за последние три дня.
- **Кабинет деканата** — очередь по сроку, смена статуса, объявления, правка пар.

## Безопасность

Студент видит только свои данные. Чужой идентификатор возвращает 404 — так же, как несуществующий. Пароли хранятся как scrypt-хеш, сессия — в `httpOnly` cookie с `Secure` и `SameSite=Lax`. Секреты только в `.env`, в клиентский бандл не попадают. Данные вымышленные, подключения к системам вуза нет.

## Ограничения

Интервью с реальными студентами не проводились: гипотезы помечены как гипотезы, в документе указан способ их проверки. Скринридер не тестировался. LLM-функция опциональна — без ключа объяснения формируются шаблоном.
