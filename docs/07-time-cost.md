## 4. Сравнение с ручным способом

| Способ | Время | Результат |
|---|---|---|
| Аналитик вручную (сбор требований, макет, прототип) | 3–5 недель | зависит от команды |
| Обычный чат с ИИ без структуры | 2–3 дня | красивый текст без проверяемого прототипа |
| Этот проект | 1,5–2 суток | запускаемый прототип + документ процесса |

Сравнение честное только по объёму: ручной способ даёт больше глубины исследования, ИИ-прототип — скорость и воспроизводимость. Что именно измерено — в отчёте после прогона (раздел 5).
