# Заявленные возможности и их границы

Честный перечень: что работает, чего не делает и почему.

## 1. Работает

| Возможность | Как проверяется | Граница |
|---|---|---|
| Вход по e-mail и паролю | тестовые аккаунты в README | пароль не восстанавливается по почте — демо |
| Профиль студента | экран профиля | редактирование данных студентом отключено |
| Расписание на день и неделю | переключатель и `?view=week` | расписание вымышленное, статично после сида |
| Переносы и отмены | отметка статуса пары | создаются сотрудником вручную |
| Оценки и зачёты, сессия | экран успеваемости | без импорта из внешних систем |
| Светофор сессии | правила в коде, тест на 3 состояниях | правила упрощены относительно устава вуза |
| Заявки и справки | создание, смена статуса, вложения от студента | без фактической выдачи документа |
| История заявки | лог событий и приложенные файлы | скан не проверяется на подлинность; лимит 5 МБ, PDF/JPEG/PNG/WebP |
| Уведомления | события четырёх типов: объявления, переносы, статусы заявок, новые сообщения в обе стороны | без push, e-mail и SMS; обновление при переходе, фонового опроса нет |
| Кабинет деканата | очередь и действия, переписка со студентами | один сотрудник, без ролей внутри деканата |
| Админка (роль admin) | CRUD по шести сущностям, поиск, перезапуск демо | журнала изменений нет, есть только общий сброс демо |
| Изоляция данных | `scripts/verify-idor.ts` | проверка на уровне приложения, не БД |
| Мобильная версия 360 px | ручная проверка + скриншоты | проверено в Chromium; iOS Safari — по эмуляции |
| Доступность | семантика, подписи, контраст AA, клавиатура, Escape в модалке | скринридер не проверялся |
| ИИ в продукте (опционально) | объяснение светофора переформулируется моделью, только если задан ключ | без ключа — шаблон; модель не меняет числа и статус |

## 2. Не работает

| Чего нет | Причина |
|---|---|
| Интеграция с системами вуза | запрещено условиями конкурса |
| Реальная выдача справок | процесс вне прототипа |
| Парсинг живого расписания | нестабильно и рискует показать неверные данные |
| Мгновенный чат в реальном времени | сообщения доставляются при обновлении страницы: WebSocket ради демо не нужен |
| Уведомления вне приложения | нет каналов и согласий |
| Оплата, стипендии, общежитие | другой домен |
| Многоязычность | не требуется |
| 2FA | не требуется конкурсом |
| Масштабирование на тысячи пользователей | SQLite и один процесс; архитектура допускает переход на Postgres |
| RAG, векторный поиск, эмбеддинги | заданием не требуются; данных (28 дисциплин, 6 заявок) слишком мало для осмысленного retrieval — поиск по совпадению решает задачу дешевле |
| Чат-бот с ИИ в кабинете | не требуется ядром, добавляет платный ключ и риск галлюцинации на демо |

## 3. Допущения, которые нужно проверить

| Допущение | Цена ошибки | Как проверить |
|---|---|---|
| Расписание — главный ежедневный вход | неверная компоновка главной | 10 интервью |
| Переносы узнают позже дня публикации | дифференциатор бесполезен | журнал группы за месяц |
| Студенту непонятно «что грозит» до сессии | светофор не нужен | вопрос на 10 студентах |
| Справку ждут дольше 3 дней | трекер не решает боль | сроки из деканата |

Пока допущения не проверены, они помечены как гипотезы в `docs/00-concept.md` и не выдаются за исследование.

## 4. Данные

Все данные вымышленные. Реальные интервью не проводились. Синтетические ответы не используются и не выдаются за реальные.

## 5. Стоимость и устойчивость

| Параметр | Значение |
|---|---|
| Прогон демо | < 1 минуты, < 1 ₽ при включённой LLM |
| Работа без LLM | полная, объяснения по шаблону |
| Падение LLM | не влияет на статусы и данные |
| Потеря БД | восстановление сидом за секунды, данные демонстрационные |
| Перезапуск сервера | сессия и данные переживают: проверено остановкой и повторным стартом; заявки, статусы и уведомления остались на месте |
| Недоступный сервер | экран «Сервер недоступен» с кнопкой «Повторить», без ложного выхода из аккаунта; восстановление проверено без повторного входа |
