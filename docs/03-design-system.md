# Дизайн-система

## 1. Принципы

1. **Один ответ на главной.** Студент открывает кабинет, чтобы узнать «что сегодня и не горит ли». Всё остальное — в одном касании от этого ответа.
2. **Статус виден без чтения.** Цвет и иконка несут смысл, текст уточняет. Цвет никогда не единственный носитель информации (доступность).
3. **Мобильный — основной.** Компоновка строится от 360 px, десктоп — расширение, а не наоборот.
4. **Спокойный интерфейс.** Никаких градиентных «дашбордов»: белый фон, один акцент, тонкие границы.

## 2. Токены

| Токен | Значение | Использование |
|---|---|---|
| `--bg` | `#F7F8FA` | фон приложения |
| `--surface` | `#FFFFFF` | карточки, панели |
| `--fg` | `#101828` | основной текст |
| `--muted` | `#667085` | подписи, метаданные |
| `--border` | `#E4E7EC` | разделители, границы карточек |
| `--accent` | `#1D4ED8` | действия, активная навигация |
| `--accent-soft` | `#EFF4FF` | фон выбранного пункта |
| `--success` | `#067647` | «всё в порядке», статус «готова» |
| `--warning` | `#B54708` | «требует внимания», перенос |
| `--error` | `#B42318` | ошибки, отмена, отказ |
| `--radius` | `12px` | карточки |
| `--radius-sm` | `8px` | кнопки, поля |
| `--space` | `4px` (шаг 1) | отступы 4/8/12/16/24/32 |

Типографика: Inter (OFL 1.1). Размеры: 28/20/16/14/12 px, межстрочный 1.4–1.5. Вес: 400/500/600. Заголовок экрана — 20–28 px, не больше.

Контраст: текст на фоне ≥ 4.5:1, крупный ≥ 3:1. Проверяется в DevTools (Lighthouse Accessibility).

## 3. Компоненты

| Компонент | Правила |
|---|---|
| `Card` | поверхность, радиус 12, граница 1 px, паддинг 16; заголовок 16/600 |
| `Button` | высота 44 px на мобильном, 36 на десктопе; primary — accent, secondary — граница; disabled снижает контраст, но остаётся читаемым |
| `Input` | высота 44, label всегда видим (не placeholder вместо label), ошибка под полем, `aria-invalid` |
| `Badge` | статус: нейтральный/успех/внимание/ошибка; текст + цвет, не только цвет |
| `EmptyState` | иконка, одна фраза, одно действие; без «иллюстраций ради иллюстраций» |
| `Skeleton` | повторяет форму контента, не крутится дольше 400 мс без текста |
| `Toast` | результат мутации, 4 с, закрывается, `role="status"` |
| `BottomNav` | 4 пункта на мобильном: Главная, Расписание, Оценки, Заявки; активный — accent + подпись |
| `DataRow` | «пара → аудитория → преподаватель» одной строкой на десктопе, тремя на мобильном |

## 4. Мобильные правила (360 px)

| Правило | Почему |
|---|---|
| Никакой горизонтальной прокрутки: `min-width: 0`, перенос длинных названий | проверяется на каждом экране |
| Тапабельная зона ≥ 44×44 px, зазор между целями ≥ 8 px | пальцем, не мышью |
| Навигация — нижняя панель, не «бургер» для 4 разделов | нужное за пару касаний |
| Таблицы → карточки, не скролл вбок | читаемость |
| Модалки → полноэкранные листы | не теряются на маленьком экране |
| Шрифт полей ≥ 16 px | iOS не зумит при фокусе |

## 5. Состояния

Каждый экран обязан иметь:

| Состояние | Как выглядит |
|---|---|
| Загрузка | скелетон формы контента ≤ 1 с, затем контент |
| Пусто | «Пока нет заявок» + кнопка «Создать заявку» |
| Ошибка | «Не удалось загрузить. Повторить» + причина, если известна |
| Успех мутации | toast + обновлённые данные без перезагрузки |
| Ошибка мутации | текст ошибки рядом с полем или toast с `role="alert"` |

## 6. Доступность

- Семантические элементы, один `h1` на экран, порядок заголовков без пропусков.
- Фокус видим: `outline: 2px solid var(--accent); outline-offset: 2px`.
- Все иконки-кнопки имеют `aria-label`.
- Статусы озвучиваются текстом: badge содержит слово, не только цвет.
- Клавиатура: вход, навигация, создание заявки — без мыши.
- `prefers-reduced-motion` отключает переходы.

## 7. Проверено аудитом

| Проверка | Результат |
|---|---|
| Один `h1` на экран, порядок заголовков | 8 экранов студентов и 5 экранов деканата — без пропусков |
| Landmarks | `main`, `header`, `nav` на каждом экране |
| Язык документа | `lang="ru"` |
| Поля без подписи | нет: либо `label for`, либо обёртка `label` |
| Иконочные кнопки без текста | нет: у всех `aria-label` |
| Контраст пар из токенов | все пары ≥ 4.5:1 (минимум 4.68) |
| Фокус видим | `outline` 2 px `--accent` с отступом |
| Модалка «Правка пары» | фокус входит в первое поле, Escape закрывает, фокус возвращается на кнопку |
| Порядок Tab | шапка → навигация → форма; ловушек нет |
| Переключатели | `aria-pressed` вместо роли tab без клавиатурного поведения |

Что не проверялось: скринридер (NVDA/VoiceOver) — требуется живой прогон, и это записано в ограничениях.
