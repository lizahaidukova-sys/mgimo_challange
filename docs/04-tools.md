# Инструменты и сервисы

Перечень всего, чем сделана работа, и роль каждого. Заполняется по факту, без «использовал всё».

## 1. Среда разработки и ассистенты

| Инструмент | Роль | Что делал именно он |
|---|---|---|
| omp (агентная оболочка) | основной исполнитель | чтение задания, каркас репозитория, документация, код, проверки |
| Claude / GPT-класс модели через omp | генерация кода и текстов | страницы, server actions, схемы, тексты интерфейса |
| Git + GitHub | версии и сдача | история итераций, доступ жюри |
| VS Code | ручная правка | мелкие правки после генерации, проверка диффов |
| Терминал (bash) | запуск и проверки | сборка, сид, тесты доступа, деплой |

## 2. ИИ для кода

| Приём | Где применён | Результат |
|---|---|---|
| Контракт `AGENTS.md` перед кодом | все фазы | меньше «дрейфа» стиля и правил |
| Поэкранная постановка задачи | UI | каждый экран проверялся отдельно |
| Промпт «сначала инварианты, потом код» | авторизация, доступ | изоляция данных реализована с первого раза |
| Самопроверка ассистентом | после каждой фазы | сборка + целевой сценарий + 360 px |

## 3. ИИ для контента и дизайна

| Задача | Инструмент | Ограничение |
|---|---|---|
| Тексты интерфейса | LLM в чате | проверены вручную на двусмысленность |
| Вымышленные ФИО и группы | LLM + ручная проверка | ни одно имя не совпадает с реальным студентом |
| Палитра и типографика | решение принято вручную по токенам | ИИ не выбирал цвета «на вкус» |
| Иконки | Lucide (ISC) | лицензия разрешает использование |
| Шрифт | Inter (OFL 1.1) | self-host, без CDN |

Генеративные изображения и видео не используются: интерфейсу они не нужны, а лицензионный риск выше пользы.

## 4. Сервисы в рантайме

| Сервис | Обязателен | Стоимость | Зачем |
|---|---|---|---|
| Node.js 22 | да | 0 | рантайм |
| SQLite (`node:sqlite`) | да | 0 | данные; встроен в Node, без компилятора |
| LLM API (OpenAI-совместимый) | нет | ~0–30 ₽ за демо | формулировка объяснений; без ключа — шаблон |
| VPS + reverse proxy | да, для ссылки | ~200–500 ₽/мес | хостинг прототипа |
| GitHub | да | 0 | репозиторий для жюри |

## 5. Что не использовалось и почему

| Не использовано | Причина |
|---|---|
| Figma | макеты не требовались, вёрстка сразу в коде |
| Генераторы изображений | нет задачи, которую они решают в ядре |
| Векторная БД / RAG | данных мало, поиск по ним не нужен |
| Docker | один процесс, лишний слой для прототипа |
| Платные UI-киты | Tailwind + собственные компоненты дешевле и без лицензионных вопросов |
| Radix Dialog | модалка правки пары обходится 30 строками: зависимость удалена после проверки, что не используется |
