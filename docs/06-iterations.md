# Журнал итераций

Записи по факту: что просили, что получили, что пришлось исправлять. Неудачные итерации оставлены намеренно — по ним видно, как шла работа.

## 20.11.2026 — подготовка

### И1. Доступ к кабинету конкурса

| Поле | Значение |
|---|---|
| Задача | Войти в личный кабинет и забрать актуальное задание |
| Действие | Вход по логину из исходных данных, обход страниц номинаций |
| Результат | Задание «Вайб-кодинг» и «ИИ-проект» прочитаны; найдена форма отправки и её условия |
| Ошибка | Прямая ссылка на материалы партнёра отдавала HTML вместо PDF (нужна сессия) |
| Исправление | Запрос файла из контекста авторизованной страницы, затем сохранение PDF |
| Вывод | У частных файлов конкурса нельзя проверять доступность через `curl` без cookie |

### И2. Оценка сроков

| Поле | Значение |
|---|---|
| Задача | Понять, реально ли уложиться |
| Действие | Разбор критериев, оценка объёма по артефактам |
| Результат | Ядро — 7–9 ч, документ — 3–4 ч, деплой — 1 ч; итого 14–19 ч при ~50 ч запаса |
| Риск | Критерий «Масштаб ИИ» закрывается документом, а не кодом; без него максимум 3/10 |
| Решение | Промпты и скриншоты пишутся по ходу, а не восстанавливаются в конце |

### И3. Формальные блокеры

| Поле | Значение |
|---|---|
| Задача | Проверить, что работа вообще может быть отправлена |
| Действие | Открыт профиль участника |
| Результат | Форма отправки закрыта, пока нет: подписанного согласия на обработку ПД, скана разворота студенческого билета, галочки Регламента |
| Решение | Это ручной этап: скачать бланк, подписать, загрузить. Без него работа не уходит |
